# مزيد | mazeed.com.ly

## الملفات
```
index.html            الصفحة الرئيسية
madkhal.html          صفحة برنامج المدخل الذكي
maydan.html           صفحة برنامج ميدان بلس
cohorts.js            الدفعات القادمة التي تعرضها الصفحة الرئيسية
tajarib-*.woff        خط تجارب (خط مزيد) للصفحات الثلاث
logo-ar.png           الشعار العربي
brand-arcs.png        أقواس الهوية في واجهة الرئيسية
brand-dots.png        نقاط الهوية في الشريط الأزرق
favicon.ico / .svg    أيقونة التبويب: النقاط الثلاث
icon-192/512.png      أيقونات التطبيق والمشاركة
apple-touch-icon.png  أيقونة الشاشة الرئيسية في آيفون
og.jpg                صورة المشاركة على واتساب ووسائل التواصل
CNAME                 ربط النطاق mazeed.com.ly
```
كل الملفات في جذر المستودع، بلا مجلدات، لأن الرفع من متصفح GitHub يُسقط المجلدات.

## ما تعدّله قبل الإطلاق
كل البيانات في أعلى السكربت داخل index.html:
- `CFG`: رقم واتساب والبريد وعدد المقاعد.
- `P`: البرامج وأسعارها. `on` السعر الحضوري و`off` الأونلاين، للتدريب كاملاً.
- الدفعات صارت في `cohorts.js` (لا داخل index.html). سطر لكل دفعة: البرنامج `p`، والتاريخ `date` و`end`، والأيام `when`، والنوبة `shift` (صباحي أو مسائي)، والوقت `time`، و`taken` عدد المقاعد المحجوزة.
  أضف دفعة جديدة بنسخ سطر وتعديله، فتظهر تلقائياً في التقويم وبطاقة البرنامج ونموذج التسجيل.
- الدفعات التي انتهت تختفي من التقويم تلقائياً، والدفعة المكتملة تظهر "مكتملة" في النموذج.
- أسعار المدخل الذكي وميدان بلس مكتوبة في مكانين: `P` في index.html، وداخل صفحة البرنامج نفسها (madkhal.html أو maydan.html). عدّلهما معاً.

## التسجيل
النموذج لا يحتاج خادماً: يجهّز رسالة الطلب كاملة ويفتحها في واتساب أو البريد ليرسلها الزائر.

## النشر على GitHub Pages
1. ارفع كل الملفات إلى جذر المستودع (لا مجلدات).
2. Settings ثم Pages: Deploy from a branch، الفرع main، المجلد / (root).
3. Custom domain: mazeed.com.ly ثم Save.
4. سجلات DNS عند مزوّد النطاق:

| النوع | الاسم | القيمة |
|---|---|---|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | اسم-حسابك.github.io |

5. بعد انتشار DNS فعّل Enforce HTTPS.
